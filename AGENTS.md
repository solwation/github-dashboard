# Repository instructions

Read and follow [AI.md](AI.md) before changing this repository.

When the user writes `/orkester`, `$orkester`, or requests orchestrated parallel work, run [.agents/skills/orkester/SKILL.md](.agents/skills/orkester/SKILL.md). `/orkester` is a repository workflow trigger; clients that reserve slash commands may require `$orkester` or a plain-language request instead.


For ordinary change requests, also follow the shared [chat intake](.orchestra/shared/ORCHESTRA.md#turn-chat-requests-into-work): create/reuse issues and start or resume scoped work unless execution is explicitly deferred, including after an idle watch ends. Reuse an active conductor; a scoped request adds no whole-backlog run or timer.

The skill is an adapter to [.orchestra/project.md](.orchestra/project.md) and the
versioned shared core from dirigenten-och-orkestern. Issue labels/state follow this
project's canonical [public/ISSUEFLOW.md](public/ISSUEFLOW.md). Merely reading the instructions starts no work; requested instruction changes are scoped work too.
