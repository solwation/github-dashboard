When the user requests orchestration or changes under the shared
[chat intake](../../../.orchestra/shared/ORCHESTRA.md#turn-chat-requests-into-work), read and follow [AI.md](../../../AI.md),
[the project policy](../../../.orchestra/project.md),
[the shared core](../../../.orchestra/shared/ORCHESTRA.md) starting from its
[read map](../../../.orchestra/shared/ORCHESTRA.md#read-map),
[Issueflow authority](../../../.orchestra/shared/ISSUE-WORKFLOW.md) and
[queue coordination](../../../.orchestra/shared/COORDINATION.md).

Preserve the requested scope. Use the available agent tools with
[the compact worker brief](../../../.orchestra/shared/WORKER.md).
The project policy owns capacity, claims, user questions, publication and idle watch.
Respect explicit deferral and reuse an active conductor. Scoped change requests start
or resume scoped work, including after an idle watch ends, without adding a whole-backlog
run or timer. Merely reading these files starts no work.
